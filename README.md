# fdmaurice-books

Here are text-based versions of the books of the Victorian Anglican theologian Frederick Denison Maurice.

These books are not currently available on Project Gutenberg or other services.

All F.D. Maurice books are, to the best of my knowledge, in the public domain in most countries, including the United States and Canada, since Maurice died in 1872.

As I improve my processing pipeline, I'll post improved versions of these books.

These books include Markdown, epub, and PDF formats.

Some of these files are preprocessed for automatic conversion to audio formats using tools such as Abogen. For example, Roman numerals are converted to spelled out numbers, and footnotes and tables of contents are removed.
