# The Works of Frederick Denison Maurice

Free digital editions of the works of F. D. Maurice (1805–1872), made
from page scans of the original nineteenth-century printings.

Maurice was one of the great English theologians of his century — a
founder of Christian Socialism, the founder of the Working Men's
College, and a teacher whose influence ran through Victorian church
and society.

Most of his books have been out of print for a hundred years, and the
scans that survive online are hard to read and harder to search. This
project exists so that anyone who wants to read Maurice can do so, in
whatever form suits them, at no cost.

## What's in this repository

Each book has its own folder containing every format we produce:

| file | what it is |
|---|---|
| `<book>.epub` | the reading EPUB — for e-readers, phones, and tablets, in your reader's own typography |
| `<book>.pdf` | a typeset book (6×9″, Baskerville) — for reading on a large screen or printing |
| `<book>-phone.pdf` | the same typography on a tall narrow page — fills a phone screen at a comfortable size |
| `<book>.docx` | a Word document — for quoting, annotating, or converting onward |
| `<book>-audiobook.m4b` | a chaptered audiobook, where one has been produced |
| `edition-notes.md` | what this edition is: the original publication data, how the text was made, and every place it deliberately differs from the print |

If none of these formats suits you, open an issue — the point of the
project is that the format should never be the obstacle.

## Faithfulness

These editions aim to reproduce what Maurice's printers actually set,
not a modernization of it. His spelling, punctuation, and
capitalization stand as printed; the italics of the original are
restored (the OCR process loses them, so they were recovered by
measuring the slant of the letterforms on the page images and reviewing
every page by hand); small capitals and the æ/œ ligatures appear as the
printer set them. Even the printers' inconsistencies are kept —
where the original spells a name two different ways, so do we.

The only deliberate departures are corrections of evident printing
errors — a broken letter, a misprinted numeral, a dropped quotation
mark. Every one of these emendations is listed, page by page, in the
book's `edition-notes.md`, so you can always know exactly where this
edition speaks and where Maurice's printer does.

## How the texts are made

Each book passes through a pipeline that combines optical character
recognition, AI language models, deterministic typographic analysis of
the page images, and page-by-page human review. Machines propose;
the printed page decides; a human editor verifies. Every word an AI
model altered is reviewed against an image of the printed line before
it is accepted, and validation tools check that quotation marks pair
correctly and emphasis is intact in the final text. The details for
any given book — including the models used and the full list of
emendations — are in its `edition-notes.md`.

## Errors

If you find a place where these editions misrepresent the printed
original — a wrong word, a lost italic, a mangled Greek phrase — please
open an issue with the book, the passage, and (if you can) the page
number. Corrections are verified against the page scans and folded
into updated editions.
